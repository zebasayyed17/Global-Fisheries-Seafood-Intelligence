## 1. Project Overview

**Global Fisheries & Seafood Sustainability Intelligence** is an end-to-end data analytics and business intelligence project designed to explore global seafood production, aquaculture development, fishing activities, seafood consumption patterns, and marine fish-stock sustainability.

The project uses multiple global datasets to identify production trends, compare fishing methods, understand seafood consumption, and examine the sustainability of fish stocks across countries.

Using SQL and Microsoft Power BI, the project transforms raw datasets into meaningful analytical insights through interactive dashboards and data visualizations.

## 2. Business Problem

Fish and seafood are important sources of food and livelihoods around the world. However, increasing seafood demand and fishing activities create challenges for marine resource management.

Some important questions arise:

- Which countries contribute the most to global seafood production?
- Is aquaculture becoming more important than traditional capture fisheries?
- Which countries depend heavily on capture fishing?
- How much of the world's assessed fish stocks remain within sustainable levels?
- How do seafood consumption patterns differ across countries?
- How has global seafood production changed over time?

The objective of this project is to use data analytics to explore these questions and provide a clearer understanding of global fisheries and seafood sustainability.

## 3. Project Objectives

- Analyze global fisheries and aquaculture production.
- Identify leading seafood-producing countries.
- Compare capture fisheries with aquaculture production.
- Examine fish-stock sustainability trends.
- Analyze seafood consumption across countries.

- Develop interactive Power BI dashboards for business insights.

## 6. Dataset Information

The project uses seven datasets covering different aspects of global fisheries.

| Dataset | Description |
|---|---|
| Aquaculture Farmed Fish Production | Production of farmed fish across countries |
| Capture Fisheries vs Aquaculture | Comparison of capture and farmed production |
| Capture Fishery Production | Fish production from capture fisheries |
| Fish and Seafood Consumption per Capita | Seafood consumption patterns |
| Fish Stocks Within Sustainable Levels | Sustainability indicators for assessed fish stocks |
| Global Fishery Catch by Sector | Fishing catch distribution by sector |
| Seafood and Fish Production | Global seafood production trends |

## 7. Power BI Dashboard

The project is organized into six analytical dashboard pages:

1. **Executive Overview** – High-level overview of global fisheries and seafood production.
2. **Aquaculture Leaders** – Analysis of leading aquaculture-producing countries.
3. **Stock Sustainability** – Exploration of fish-stock sustainability indicators.
4. **Production by Fish Type** – Analysis of production across fish types.
5. **Fishery Sectors** – Comparison of global fishery catch by sector.
6. **Seafood Consumption** – Analysis of seafood consumption across countries.

## 8. Project Workflow

The project follows an end-to-end data analytics workflow:

1. Data Collection – Gather multiple publicly available global fisheries datasets.
2. Data Understanding – Inspect dataset structures, columns, years, and geographical coverage.
3. Data Quality Assessment – Examine missing values, duplicate records, and data consistency.
4. Data Preparation – Prepare datasets for analytical exploration.
5. SQL Analysis – Perform data querying and analytical investigation.
6. Power BI Development – Build interactive dashboards and visualizations.
7. Business Insights – Interpret the results and identify meaningful patterns.
